本项目回答判断的流程：问题监测完成搜索 → 回答分析保存判断 → 后端汇总 → 概览读取。这部分提示词维护在问题监测对应的 Skill。

竞品小卡另复用竞品对照的推荐结果、介绍及证据，不新增概览推荐 Agent 或提示词。这里维护小卡导航，推荐交付标准统一在竞品提示词中。用户直接选参照留在概览；“查看详情”进入竞品页。未选时只展示满足推荐条件的对象；已选参照继续保留，仅展示完整可比的指标。原始缺数及审核记录继续保留在详情。

概览始终保留一张紧凑参照小卡。竞品页未选时最多展示 3 个推荐并突出首项；选定后承接“漏在哪道题 → 原回答依据 → 具体改什么 → 复测结果”，默认展开第一条真实漏题、多题可切换，同题平台分别保留。这条行动主线不展开在概览小卡中；百分比和待复测状态不扩成新的主卡，也不因选择参照自动执行改动或复测。
