# 内容资产

[返回六个页面](../README.md)

目标是理解产品、找到已有文章/研究/案例，供后续选题和改进使用。GitHub 仓库是支持的一种输入，不是另一个页面分类。

## 产品与内容理解

**状态：已有独立仓库调查 Workflow，尚未作为本页的自动调查 Agent 接入。** 原有路径保持有效。

| 调整内容 | 文件 |
| --- | --- |
| 整个调查与选题流程 | [repository-topic-discovery/SKILL.md](../repository-topic-discovery/SKILL.md) |

模型与推理强度沿用调用者当前 Codex CLI 配置。`--stage-timeout`、`--project-timeout`、`--workers` 控制超时与并发；输入/交接硬预算仍在运行器常量中。研究与审核可用网页工具，出题与修订只消费材料，默认最多一次修订后复审。这里给出真实参数位置，没有新增一份不生效的配置。

调查之后的出题和审核归属 [问题监测](问题监测.md#从-github-入口调查后再出题)，共用原 Workflow，不复制调查提示词。
