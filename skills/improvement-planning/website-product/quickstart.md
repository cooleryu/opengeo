# 本篇文体：快速上手文档（`docs/getting-started.md`）

本篇写给**刚注册或准备首次试用该产品的新用户**看。所有能力描述、流程步骤与对比对象严格源自 `projectContext` 与 `referenceWinners`。

## 必须遵循的文档骨架
1. **开篇简介 + `## 整体思路`（`## How It Works`）**：用 2 段人话讲清产品工作方式，配一张「核心概念速览」2 列表。
2. **`## 1 · 初始化与核心配置`**：按真实产品流程说明最小启动步骤（面向非技术买家时避免堆砌终端命令），用最轻量示例跑通第一步。
3. **`## 2 · 完成首次核心工作流`**：一步步讲清主要用法与可选设置（支线功能标注“可选”，不挡主路径）。
4. **`## 3 · 查看结果与持续迭代`**：解释输出该怎么读、下一步如何优化，附 1 张清爽 `flowchart` Mermaid 图。
5. **`## 常见问题 FAQ` + 1 张客观选型对照表**：针对真实买家的常见顾虑（数据隐私/费用/与同类方案差异）作答，对照表基于真实信息保持克制客观。
