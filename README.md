**开源 · 本地运行 · SQLite 存储**

OpenGEO 是一个 AI 搜索可见性工作台。围绕同一道问题，查看不同平台的回答、引用网页和历史记录，再将发现的缺口转成可审核、可跟踪的改进任务。

> 当前公开版本：**2026-10-31 开发版**。以下对应仓库已有代码；项目整体优化仍在开发，不在此版本中。

## 现在能做什么

| 页面 | 你可以做什么 |
| --- | --- |
| **概览** | 查看品牌提及、自有内容引用和各平台结果；进入对应回答；拖拽调整重点改进的显示顺序，按项目保存。 |
| **问题监测** | 管理核心与候补问题、中英问法；单题或批量搜索；查看进度、停止后续搜索，并打开本次结果。 |
| **回答详情** | 左边看实际问法，右边直接读完整回答；展开引用网页，切换最新回答与历史回答。 |
| **竞品对照** | 从已有回答发现候选，选一个主要对标对象；按同题、同语言、同平台对照，追溯匹配依据。 |
| **内容资产** | 查看已有内容、关联问题和引用记录，整理需要补齐的内容或证据。 |
| **改进与追踪** | 从单题证据生成方案、独立审核，登记实施，再按保存的条件跟测。 |
| **流量数据** | 连接 Umami 查看访问与 AI 来源；有转化记录时查看转化。 |

### 一道问题，从搜索到回看

1. **选择问题、语言和采集平台。** 点击搜索后确认；费用上限默认关闭，需要时再开启。
2. **搜索过程中看进度。** 可以停止后续请求，已完成的结果保留。
3. **直接打开本次结果。** 问法、回答和引用网页放在一起，历史回答留在同一道题里。

采集到的新结果自动保存到 SQLite，并供列表、详情和概览读取；不用每次让 AI 手工整理文件。项目、语言和平台分开记录，旧观测不会被新结果覆盖。

**提及品牌与引用自有内容分别统计。未测、未知和真实零值分开；网页搜索命中不混成 AI 提及率。**

## 支持哪些平台

| 入口 | 当前能力 |
| --- | --- |
| **DeepSeek 搜索 API** | 单题、批量搜索及每日问题计划；返回网页搜索结果。 |
| **千问 API / 豆包 API** | 已配置后可执行联网回答采集，保存回答和供应商返回的引用。 |
| **ChatGPT / Google 网页** | 可展示已保存的回答或搜索记录；尚未接入网页自动采集，公开版不附带历史记录。 |
| **分析模型** | 配置 API 模型进行拟题、回答审核、方案生成与独立审核；ChatGPT 订阅连接可用于部分分析操作。 |

API 联网回答不等于消费端 App 的回答。查看已有记录不会发起新搜索；主动搜索和已启用的计划可能产生费用。每日计划需要本地服务持续运行，其真实定时触发仍待验证。

## 从回答走向改进

**问题与证据 → 单题方案 → 独立审核 → 实施登记 → 同条件跟测**

方案生成和审核分开判断。修改方案后重新审核；由你决定是否实施、是否启用跟测。没有实施或没有可比观测，就不显示成已经改善，也不自动发布内容。

## 开始使用

准备 **Node.js 24** 和 npm。

```sh
git clone https://github.com/cooleryu/opengeo.git
cd opengeo
npm install
cp .env.example .env.local
npm run dev
```

打开 [localhost:4327](http://127.0.0.1:4327)。

1. **浏览页面：** 凭据留空即可查看两个空示例项目。
2. **配置材料：** 编辑 [example-project.json](src/lib/geo/data/example-project.json) 或 [example-project-two.json](src/lib/geo/data/example-project-two.json) 中的项目资料和资产，保留结构与项目 ID。当前尚无应用内创建项目或导入材料入口。
3. **连接服务：** 在「设置」配置搜索服务与分析模型，或使用 [.env.example](.env.example)。保存配置不发请求；连接测试、拟题、搜索和分析可能收费。

搜索费用上限不覆盖独立的分析模型费用。密钥、登录状态和业务数据库留在本地；调用服务时会向所选供应商发送必要材料。公开版使用空示例，不附带个人项目和搜索证据。

## 当前边界

- **项目整体优化**（重点优化 / 深度优化）仍在开发，本次公开版保留单题改进。
- **从仓库自主调查**已有独立 [选题 Skill](skills/repository-topic-discovery/SKILL.md)，尚未接入应用建项目和材料导入。
- **重新拟题与历史候选的完整合并**仍待完善；已有搜索观测独立保留。
- **自动执行完整五环、自动发布、真实增长保证**均不在当前能力承诺内。内部审核通过不代表流量或转化已改善。
